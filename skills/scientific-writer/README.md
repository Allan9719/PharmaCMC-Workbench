# Scientific Writer — Writing Quality Module

> Module of [PharmaSee CMC Workbench](../../README.md)

Scientific Writer provides writing quality assurance using SRW methodology and 5-pass audit.

## 4 Modes

| Mode | Purpose |
|------|---------|
| WRITE | Draft scientific sections using SRW 7-step workflow |
| REVIEW | 5-pass writing quality audit with severity ratings |
| DIAGNOSE | Structural diagnosis against section models |
| LEARN | Interactive scientific writing instruction |
