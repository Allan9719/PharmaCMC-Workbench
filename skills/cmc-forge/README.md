# CMC Forge — Execution Engine

> Module of [PharmaSee CMC Workbench](../../README.md)

CMC Forge is the primary execution engine for CMC deliverables.

## 4 Modes

| Mode | Purpose |
|------|---------|
| DRAFT | Generate CMC documents (PPQ, Module 3, comparability, tech transfer) |
| ASSESS | Risk and gap analysis (Red-Yellow-Green, FMEA, readiness) |
| PLAN | Project planning (workplans, roadmaps, deliverable decomposition) |
| TRAIN | Knowledge assets (training outlines, FAQ, checklists) |

## Key Resources

- `SKILL.md` — Skill definition and trigger rules
- `templates/` — 5 document scaffolds
- `playbooks/` — 6 domain knowledge scripts
- `references/` — 7 operational guidance files
- `examples/` — 2 worked mock outputs
- `evals/` — 10 single-module evaluation scenarios
